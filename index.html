Agents

Dispute Copilot

A multi-agent assistant for “what is this charge” and “I was charged twice.” A validator checks every fact against the ledger, and fraud or expired disputes go to a person.Details +

How it works

Guardrails → router (LLM with rule fallback) → investigator (duplicate, subscription, fraud signals, notice deadline) → Reg Z / Reg E retrieval → explainer returns claims that cite evidence → deterministic validator → one retry, then rules, then a human. Disputes are drafted only after the customer confirms and are approved by a reviewer against a payload hash.

Scope & limitations

58 tests pass. On 136 templated cases the rule-based mode passes all of them; on 25 hand-written messy messages it passes 44%, which is the gap the model router is meant to close. Model-backed numbers are not published yet. Synthetic data only; the fraud score is hand-weighted, not trained; policy text is my own summary, not legal guidance.

Harbor

A private, trauma-informed space for women who’ve experienced sexual violence to say what they can’t say out loud yet, and be met with belief instead of questions.Details +

How it works

On-device listener: safety checks first (self-harm → 988, danger → 911 and quick exit, recent assault → time-sensitive care, no pressure), then theme-aware replies that never ask why or for details. Tap-to-say feelings, full-screen cards to show a nurse or counselor (read aloud), private journal, grounding, options, real survivor talks, and a safety plan. Scope & limitations

14 listener tests cover crisis routing and screen every reply for blaming or doubting language. Rule-based listener by default; an optional on-device model is screened the same way. Not yet reviewed by a rape crisis center, which is the next step before anyone relies on it. US resources only.

How it works

Evidence Search

A document search API that keeps tenants’ data separate and returns versioned sources. Includes access-control tests and retrieval evaluation.Details +

How it works

Server-side bearer identity → reader/writer authorization → SQLite document store → overlapping chunks → tenant-local BM25 → content-versioned evidence. Integration tests cover access isolation, spoofed tenant fields, persistence, deletion, and content-free auditing.

LLM Evaluation Gates

A tool for comparing two sets of model outputs and checking whether a release hides regressions, costs too much, or runs too slowly.Details +

How it works

Labeled cases and paired predictions → exact coverage validation → correctness and citation checks → slice metrics → paired bootstrap interval → latency/cost budgets → release decision. A synthetic 18-case fixture demonstrates a refusal regression hidden by aggregate improvement.

Resilient Inference Service

A Python adapter for handling slow or failing model calls, with concurrency limits, deadlines, retries, and a circuit breaker.Details +

How it works

Caller → deadline including queue wait → semaphore → retryable provider call → metrics and circuit state. Python 3.11 structured timeout propagates cancellation.

Scope & limitations

Adapter library only: no HTTP server, real model provider, or production load test. Circuit state is process-local and cooldown recovery is simplified rather than single-probe half-open.
