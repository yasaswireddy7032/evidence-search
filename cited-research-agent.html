Cited Research Agent

A bounded research agent with local document tools, exact-quote citation checks, and an optional Ollama adapter.

Code, tests & setup ↗ Download source ↗

How it works

Question → model decision → validated search/read tools → answer with source quotes and document hashes, or abstention. Python limits steps and rejects unknown tools and unread citations.

Run the demo

python app.py
python -m unittest -v

Python 3.10+; no Python dependencies. The default demo uses scripted model decisions. See the README for optional Ollama setup.

What I tested

Nine local tests passed. The recorded output is from the scripted demonstration, not a live model or production benchmark.

Limits

Nine local tests and a scripted demo pass. Live-model execution has not been validated. Exact quotes do not establish semantic entailment; lexical search misses paraphrases. No web access or filesystem tool is exposed to the model.
