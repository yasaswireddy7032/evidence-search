Approval Triage Agent

A support-triage agent with policy lookup, persisted proposals, human approval, and idempotent local assignments.

Code, tests & setup ↗ Download source ↗

How it works

Ticket → model-selected policy lookup → validated routing proposal → pending SQLite record → human confirmation of the exact proposal → atomic local assignment and audit.

Run the demo

python app.py
python -m unittest -v

Python 3.10+; no Python dependencies. The default demo uses scripted model decisions. See the README for optional Ollama setup.

What I tested

Nine local tests passed. The recorded output is from the scripted demonstration, not a live model or production benchmark.

Limits

Nine local tests and a scripted demo pass. Optional Ollama adapter; live-model behavior is not yet validated. Approval is a local CLI boundary, not authenticated multi-user authorization. No replies are sent and no external ticket system is modified.
