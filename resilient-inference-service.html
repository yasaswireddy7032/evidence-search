Resilient Inference Service

An asynchronous inference adapter with bounded concurrency, deadlines, transient retries, and a circuit breaker.

Download source ↗ View on GitHub ↗

How it works

Caller → deadline including queue wait → semaphore → retryable provider call → metrics and circuit state. Python 3.11 structured timeout propagates cancellation.

Run it locally

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
python -m unittest -v

Engineering boundaries

Adapter library only: no HTTP server, real model provider, or production load test. Circuit state is process-local and cooldown recovery is simplified rather than single-probe half-open. Add shared quotas, randomized backoff, tracing, authenticated endpoints, provider-specific error mapping, and overload tests.
