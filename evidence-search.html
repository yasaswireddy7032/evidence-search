Evidence Search

An authenticated retrieval API with tenant isolation, SQLite persistence, versioned citations, and BM25 evaluation.

Download source ↗ View on GitHub ↗

How it works

Server-side bearer identity → reader/writer authorization → SQLite document store → overlapping chunks → tenant-local BM25 → content-versioned evidence. Integration tests cover access isolation, spoofed tenant fields, persistence, deletion, and content-free auditing.

Run it locally

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
python -m unittest -v

Engineering boundaries

Lexical retrieval misses paraphrases, and the service rebuilds an in-memory index per request. Bearer credentials are configured on the server; a production deployment needs an identity provider, encrypted transport and storage, rate limits, per-document access rules, audit atomicity, and load testing. The API returns evidence and does not invoke a language model.
