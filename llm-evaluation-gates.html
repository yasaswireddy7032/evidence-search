LLM Evaluation Gates

A paired evaluation harness with slice regressions, bootstrap intervals, dataset fingerprints, cost budgets, and release gates.

Download source ↗ View on GitHub ↗

How it works

Labeled cases and paired predictions → exact coverage validation → correctness and citation checks → slice metrics → paired bootstrap interval → latency/cost budgets → release decision. A synthetic 18-case fixture demonstrates a refusal regression hidden by aggregate improvement.

Run it locally

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
python -m unittest -v

Engineering boundaries

Exact-match grading is deliberately narrow. A valid citation ID does not prove factual entailment. The one-case demo is a smoke example, not evidence of model quality. Add blinded human labels, semantic graders, safety slices, and confidence intervals for serious release decisions.
